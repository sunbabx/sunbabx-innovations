# Sunbabx Innovations

This workspace now contains two separate app folders:

- sunbabxfe: frontend React + Vite app
- sunbabxbe: backend Express API server

## Run locally

Frontend:
- cd sunbabxfe
- npm install
- npm run dev

Backend:
- cd sunbabxbe
- npm install
- npm run dev

## Build

Frontend:
- cd sunbabxfe
- npm run build

Backend:
- cd sunbabxbe
- npm run build
